Instead, it sends a Linux input code directly to the shell or the app you are running. Its exact behaviour depends on what you are currently doing:

1. On the Empty Command Line (Bash/Zsh)
If you have just been typing commands at a standard prompt:
- In Bash: Pressing Page Up usually does nothing or outputs a generic ~ symbol.
- In Zsh: It cycles backwards through your command history based on the first few letters you typed (acting like a smart history search).

2. Inside Text Editors or Viewers (Vim, Nano, Less)
When you are actively editing a file or reading a manual page (man), the terminal passes the key straight into the application.
- It scrolls the text cursor up by one full screen within that specific file or document.

How to make it actually scroll the terminal window
If you want to use the Page Up key to look back at command outputs that have already scrolled off the screen, you must combine it with Ctrl + Shift:
- Ctrl + Shift + Page Up — Scrolls the whole window up one full page.

How to Bind Shift + Page Up to Scroll
1. Open Windows Terminal.
2. Open the Settings file by pressing Ctrl + Shift + , (comma). This opens your settings.json file in your default text editor (like Notepad or VS Code).
3. Scroll down to the "actions" or "keybindings" section.
4. Paste the following two blocks of code into the actions list:
{ "command": "scrollUpPage", "keys": "shift+pgup" },
{ "command": "scrollDownPage", "keys": "shift+pgdn" }
5. Save and close the file (Ctrl + S). The changes will apply instantly without needing to restart the terminal.

Alternatively: Change it via the Graphical Settings Interface
If you prefer not to edit the JSON file directly, you can do it using the settings menu:
1. Open Windows Terminal and press Ctrl + , (comma) to open the standard Settings UI tab.
2. In the left-hand sidebar, click on Actions.
3. Scroll down until you find Scroll page up and click the edit pencil icon next to it.
4. Press Shift + Page Up on your keyboard, then click the checkmark to accept.
5. Do the same for Scroll page down using Shift + Page Down.
6. Click Save in the bottom-right corner.
